# Python Calculator

A simple and beginner-friendly **Calculator application built using Python**. This project performs basic mathematical operations and takes input from the user to calculate and display the result.

## Features

* Addition
* Subtraction
* Multiplication
* Division
* User-friendly input handling
* Displays the calculated result

## Technologies Used

* **Python**

## How It Works

The program takes two numbers as input from the user and asks them to select an arithmetic operation. Based on the selected operation, the calculator performs the calculation and displays the result.
